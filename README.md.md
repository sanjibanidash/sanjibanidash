Built a regression workflow using U.S. Energy Information Administration
(EIA) data to study electricity forecast errors.

-   Processed **209,830 records**
-   Compared multiple regression models
-   Tracked experiments with MLflow
-   Explored retraining decisions and data-drift monitoring

**Reported result:** candidate model R² improved from **0.9216 to
0.9312** in the project experiment.
